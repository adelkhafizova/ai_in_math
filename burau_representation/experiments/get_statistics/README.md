Experiment dedicated to obtaining graphs of distibution of matrices obtained at each step of algorithm (which is located at main.py, for explanation of what it does read README of /experiments). 

Some selected histograms are located at plotsmod2 and plotsmod3 folders (which correspond to running algorithm for field being laurent polynomials modulo 2 and 3 respectively). 

The name of a picture is histogram_n, where n is a iteration for which histogram is taken, if _big specified, then it means that it was run on nebius vm with bigger parameters. Parameters of algorithm are specified inside of a histograms.
